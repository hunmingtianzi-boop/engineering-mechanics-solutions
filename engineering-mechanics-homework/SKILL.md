# 工程力学作业

1. **核对题号与教材版本。** 按用户指定的清单或章节范围核对题号、小问和图中数据。题干与图示有矛盾时，在解答里说明采用的条件及其影响。课程作业按已知的作业次数和提交要求命名。
2. **逐题写清条件和过程。** 依次给出题号、题意、已知条件、求解要求、必要题图、解答和答案。说明研究对象、正方向和关键关系，再给出代入及带单位的结果。检查平衡、单位和数量级，区分假定方向与解出的拉压方向。
3. **在教材题图上标注。** 紧裁图形，保留尺寸、支座、作用点和子图编号，并注明教材出处。用深红色 SVG 或 TikZ 矢量箭头、截面虚线及短标签标在图上，避开原有数字和尺寸线。研究对象、作用与反作用在原图上难以区分时，旁边补一张分体受力小图。题目要求的轴力、剪力、弯矩等结果图单独画，并核对符号、正负和分段位置。
4. **紧凑排版并保持同题同页。** 采用 A4、黑白正文和公式、普通答案段落，深红色用于图上标注。短题可同页排列，或把窄题图与短解答并排。用不可拆分的题块保留题干、题图、过程和答案，长题优先调整图幅和空白，保持字号可读。页眉右侧默认署名「夜霜曦雪」，可按用户指定替换。可从 [作业模板](assets/worksheet.tex) 起步。
5. **核对实际成品。** 按 [编译和预览检查](references/compile-and-check.md) 检查字体、裁图、箭头、公式及分页。交付经检查的 PDF，按需要保存可复编源稿和题图。公开版只发布用户指定的文件，检查署名、学号和本机路径等信息。
