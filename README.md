# 工程力学教材习题解答

夜霜曦雪 · 章末习题解题笔记

覆盖吴昌聚主编《工程力学》（浙江大学出版社，2023 年 3 月第 1 版第 1 次印刷，ISBN 978-7-308-23268-5）第 2–13 章的 **106 道编号章末习题**。第 1 章为绪论，未设编号章末习题。

[查看 LaTeX 排版的完整 PDF](pdf/engineering-mechanics-solutions.pdf)

每题依次列出**题意、已知条件、求解要求、解答和结果**。题目用自己的话转述，保留计算所需的尺寸、材料参数、荷载和支承条件。依赖图形的题配有自绘题图，红色箭头表示力或力偶。轴力图、扭矩图、剪力弯矩图和应力圆列在相应解答中。
